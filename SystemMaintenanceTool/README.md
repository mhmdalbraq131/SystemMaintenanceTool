# أداة صيانة النظام الاحترافية — System Maintenance Tool Professional

## نظرة عامة
تطبيق سطح مكتب احترافي لأنظمة ويندوز يجمع بين المراقبة والإدارة والصيانة والتشخيص والإصلاح في واجهة واحدة موحدة.

## الميزات
- **15 صفحة وظيفية**: لوحة المعلومات، الأداء، العمليات، التخزين، الشبكة، الأمان، الصيانة، مركز الأوامر، الخدمات، بدء التشغيل، معلومات النظام، التشخيص، سجل الأحداث، التقارير، الإعدادات
- **بيانات حقيقية من النظام**: psutil, WMI, Windows APIs, subprocess
- **واجهة عربية RTL**: تصميم مستقبلي داكن
- **تصدير متعدد الصيغ**: JSON, CSV, TXT, HTML
- **مراقبة مستمرة**: CPU, RAM, Disk, GPU, Network
- **تشخيص النظام**: فحوصات شاملة مع مؤشر صحة تقديري
- **مركز أوامر**: مكتبة أوامر ويندوز مع تنفيذ مباشر
- **إدارة الخدمات**: تشغيل/إيقاف/إعادة تشغيل خدمات ويندوز

## المتطلبات
- Windows 10/11
- Python 3.10+
- المتطلبات في `requirements.txt`

## التشغيل
```bash
pip install -r requirements.txt
python main.py
```

## بناء EXE
```batch
build_windows.bat
```

## البنية
```
SystemMaintenanceTool/
├── main.py                 # نقطة الدخول
├── requirements.txt
├── build_windows.bat
├── config/settings.py
├── app/
│   ├── core/               # السمة، الإعدادات، التسجيل
│   ├── services/           # خدمات قراءة بيانات النظام
│   ├── diagnostics/        # نظام التشخيص

│   ├── reports/            # مولد التقارير
│   ├── maintenance/        # خدمة الإصلاح
│   ├── security/           # الأمان
│   ├── models/             # نماذج البيانات
│   ├── widgets/            # عناصر واجهة مخصصة
│   ├── monitors/           # مراقبات النظام (QThread)
│   ├── pages/              # 15 صفحة واجهة
│   └── ui/                 # النافذة الرئيسية
```
