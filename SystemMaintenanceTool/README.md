# SystemMaintenanceTool

أداة صيانة ومراقبة لنظام Windows بواجهة عربية خفيفة.

## التشغيل بدون PySide6

المشروع أصبح يستخدم Tkinter المدمج مع Python بدل Qt/PySide6. لذلك لا تحتاج إلى تنزيل PySide6 أو مكوناته الضخمة.

المتطلبات التشغيلية:
- Python 3.10+
- psutil
- pywin32 على Windows
- WMI على Windows

إذا كانت هذه الحزم مثبتة مسبقًا، شغّل مباشرة:

```powershell
py main.py
```

## الوظائف الحالية

- لوحة مراقبة CPU/RAM/Disk والعمليات ومدة التشغيل.
- معلومات Windows والجهاز.
- إدارة العمليات وعرض أعلى العمليات استهلاكًا.
- التخزين والشبكة.
- فحص أمان أساسي عبر WMI عند توفره.
- صيانة Windows: SFC وDISM وCHKDSK وDNS وWinsock.
- تنظيف الملفات المؤقتة.
- عرض خدمات Windows وعناصر بدء التشغيل.
- مركز أوامر CMD مع تنفيذ غير متزامن.
- إنشاء تقارير TXT وJSON.
- واجهة عربية مع التنقل من اليمين.

الملفات القديمة الخاصة بـ PySide6 بقيت في المستودع مؤقتًا حتى لا نفقد وظائفها السابقة أثناء الانتقال. نقطة الدخول الجديدة لا تستوردها، وبالتالي لا تؤثر على التشغيل.
